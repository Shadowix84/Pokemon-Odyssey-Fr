# Aider la traduction

Merci de vouloir donner un coup de main ! Voici comment aider, du plus simple au plus utile.

## 1. Signaler un bug ou une faute

Ouvre une issue avec le formulaire **[Signaler un bug ou une faute](https://github.com/Shadowix84/Pokemon-Odyssey-Fr/issues/new/choose)**.

Un bon signalement contient :
- ta version (elle s'affiche dans le menu principal : « Continuer FR4.x.x ») ;
- l'endroit exact dans le jeu (lieu, personnage, menu ou combat) ;
- le texte tel qu'il s'affiche ;
- une capture d'écran, si possible.

Avant d'en ouvrir une, jette un œil aux [issues existantes](https://github.com/Shadowix84/Pokemon-Odyssey-Fr/issues) : le problème est peut-être déjà signalé.

## 2. Proposer une meilleure traduction

Une phrase te semble maladroite, un terme mal choisi ? Utilise le formulaire **[Proposer une meilleure traduction](https://github.com/Shadowix84/Pokemon-Odyssey-Fr/issues/new/choose)**.

Pour qu'une proposition puisse être reprise, elle doit respecter les choix de la traduction :
- tout le monde **tutoie** Nyx, et les accords sont au **féminin** ;
- les mots italiens et romains de Kitt et Rockey sont **gardés** ;
- les noms propres inventés restent tels quels, les noms descriptifs sont traduits ;
- les noms officiels français sont utilisés quand ils existent ;
- chaque personnage garde sa façon de parler.

Garde aussi en tête que la place à l'écran est limitée : une proposition plus courte a plus de chances d'être reprise.

## 3. Tester la dernière version

À chaque version, quelques points sont à vérifier en jeu. Pour la **FR4.1.9** :

- [ ] Le menu principal affiche « Continuer FR4.1.9 »
- [ ] Première Strate : le réveil de Karin et la partie de pierre-feuille-ciseaux
- [ ] Première Strate : secouer une plante (« Combien de fois ? », « Tu obtiens … Baie(s) Oran ! »)
- [ ] Labo Abandonné : l'entrée d'Annette (« TREMBLEZ, SCÉLÉRATS ! »)
- [ ] Deuxième Strate : la rencontre avec Kitt et les essais de mot de passe devant le repaire
- [ ] Repaire des Voleurs : le discours d'Olympia à Brody
- [ ] Désert de Golgonda : Rockey, puis « Deuxième Strate : terminée ! »
- [ ] Troisième Strate : lire une stèle (« Une feuille est attachée à la stèle : »)
- [ ] Troisième Strate : le combat contre Manu
- [ ] Café Meumeu : Malna et sa façon de parler (« Povcatvota… »)

Si tout va bien, tu peux le dire sur le [Discord](https://discord.gg/c7SMEeAm9s). Si quelque chose cloche, ouvre une issue.

## Ce qu'il ne faut pas faire

- Partager ou demander une ROM : seul le patch est distribué.
- Envoyer des pull requests : la traduction est générée par des outils qui ne sont pas dans ce dépôt. Passe par les formulaires, c'est plus rapide.
