# Politique de sécurité

## Fichiers officiels

Le seul patch officiel de cette traduction est celui publié dans la section Releases de ce dépôt. Ne télécharge pas de ROM ou de patch « Pokémon Odyssey FR » depuis d'autres sources : ils pourraient contenir des fichiers malveillants.

## Signaler un problème de sécurité

Si tu repères un lien suspect, un faux patch ou un fichier douteux se faisant passer pour cette traduction, préviens-moi sur le [serveur Discord](https://discord.gg/NWvBjU3kya), dans le salon prévu pour contacter un modérateur.

Les bugs de jeu et les fautes de traduction ne se signalent pas ici : ouvre une [issue](https://github.com/Shadowix84/Pokemon-Odyssey-Fr/issues/new/choose) avec le formulaire de signalement.
